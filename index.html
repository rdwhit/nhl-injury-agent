The agent runs automatically every 3 hours on GitHub (5:30pm ET, 8:30pm ET, and so on), pulls CBS Sports' NHL injury report, and logs every status change here. A player who drops off the report is logged as cleared / no longer listed. Refresh only reloads what the agent has already saved; to force a new check, use Run workflow on GitHub's Actions tab.
